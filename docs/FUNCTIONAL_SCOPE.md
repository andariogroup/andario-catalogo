# Alcance funcional

Andario Catálogo publica un catálogo de un negocio. Sirve para ropa, café, vehículos, electrónica, servicios e intangibles porque el modelo es categoría, atributo, variante, precio y disponibilidad. No hay módulos por industria.

El visitante puede explorar, buscar, filtrar, ver precio publicado, elegir variante, compartir, armar una lista de interés, pedir cotización y abrir WhatsApp.

No hay checkout, pasarela, pedido, factura, inventario numérico, CRM, reseñas, cupones, usuarios compradores, registro público ni WhatsApp Cloud API.

Una cotización es una solicitud. El precio publicado no es una oferta cerrada. El sistema no calcula impuestos ni envío: entregas y condiciones son texto escrito por el negocio.

Las políticas no se publican solas. Salen en el pie solo cuando el negocio las marca como publicadas y escribe el contenido.
